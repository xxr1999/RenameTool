# RenameTool —— tkinter 高级批量重命名工具

一个基于 Python 标准库 tkinter 的批量重命名 GUI 工具。**只处理文件，绝不重命名任何文件夹。**

---

## 一、功能简介

- **文件添加**
  - 【选择文件夹】扫描目录，可勾选「包含子文件夹」决定是否递归扫描子目录。
  - 【添加文件】直接多选文件加入。
  - **拖拽添加（可选功能）**：系统安装了 `tkinterdnd2` 时启用，可拖入文件或文件夹（拖入文件夹时同样遵循「包含子文件夹」复选框）；未安装时拖拽自动禁用，状态栏右侧固定提示「拖拽功能未启用，如需请安装 tkinterdnd2」，不会报错。
  - 按**文件绝对路径去重**，重复文件自动跳过，表格不出现重复行。
  - 后缀筛选（如 `jpg,png,txt`，逗号分隔、不区分大小写）在添加时立即生效；留空表示关闭筛选。
- **改名规则（可同时启用，固定执行顺序）**
  1. 正则替换（支持捕获组 `\1`，可切换大小写敏感，可勾选「正则包含扩展名」）
  2. 添加前缀 / 后缀（两个独立输入框，可只填一个）
  3. 顺序编号追加（**必须勾选开关**才生效：在文件名末尾追加 `_数字`）
  4. 时间插入（不插入时间 / 修改时间 / 创建时间；自定义时间格式）
  - 所有规则默认**只作用于主文件名，保留原始扩展名**。
  - 编号在前、时间在后，例如：`原名_001_20240101_120000.txt`
- **`{num}` 占位符 + 独立的全局编号计数器**
  - 第 5 组「全局编号计数器」拥有自己独立的起始值、步长、补零位数、排序依据，**与「启用顺序编号」复选框完全无关**：无论该复选框是否勾选，`{num}` 都能正常解析。
  - `{num}` 可写在前缀、后缀、正则替换的「替换为」中；计数器**只替换占位符，绝不自动追加任何字符、绝不自动加下划线**。
  - 典型用法：正则填 `^.*$`（或 `.*`，两者等价可用；**不勾选**「正则包含扩展名」）、替换为填 `{num}`，即可把主文件名整体换成编号，一步得到 `20.txt` 这样的纯数字文件名。
  - 需要输出字面量 `{num}` 时写作 `{{num}}`。
  - 两个编号模块互相独立，可同时使用：先解析 `{num}`，再由「顺序编号追加」在末尾加 `_数字`。
- **排序依据（仅决定编号分配顺序）**：表格顺序 / 文件名称 / 修改时间 / 文件大小。
  表格显示顺序永远是文件加入的先后顺序，不会被改变；文件名称排序使用**不区分大小写的普通字符串排序**（不引入任何第三方排序库）。
- **预览阶段完整校验**（全部在确认前拦截，问题行红色高亮）：
  1. 重名冲突（多个文件生成同一个新名字）
  2. Windows 非法字符 `\ / : * ? " < > |`（前缀后缀同样纳入校验）
  3. Windows 保留名（CON、PRN、AUX、NUL、COM1-COM9、LPT1-LPT9）
  4. 新路径总长度超过 255 字符
  5. 编号参数非法、正则语法错误
  6. 表格为空，或全部新文件名与原始文件名完全一致时，确认按钮保持禁用
- **执行与事务**
  - 点击【确认执行改名】→ 二次确认弹窗显示「一共将要修改 N 个文件」。
  - 执行前重新校验文件是否存在、绝对路径是否与预览阶段一致；不一致则放弃本次改名并提示重新预览。
  - 任意一个文件改名失败（含被占用等系统原因）→ 自动回滚已改名的文件；回滚失败的文件清单弹窗通知。
- **撤销**
  - 仅内存保存，只可撤销本次程序运行内**最近一次成功**的改名批次；关闭软件即丢失。
  - 只恢复文件名，不改动文件所在路径。
  - 撤销前逐个检查文件是否存在，失败清单弹窗列出。
  - 没有可撤销记录时撤销按钮为灰色禁用；撤销后立即清空记录并保持禁用。
- **其它**
  - 修改任意规则参数触发预览刷新，使用 `after()` 实现 200ms 防抖；表格超过 500 条时状态栏提示「文件较多，预览刷新可能较慢」。
  - 表格支持行多选，但多选**不限定**改名范围，改名始终对表格内全部文件生效。
  - 窗口最小尺寸 900×650，可自由缩放；界面分为文件选择与筛选区、改名规则配置区、预览表格区、操作按钮区（含状态栏）4 个区域。
  - 直接关闭窗口不做确认，程序立即退出。

## 二、源码运行方式

环境要求：Windows + Python 3.8 及以上（自带 tkinter）。

```bat
:: 1) 进入源码目录
cd /d 源码所在目录

:: 2) 直接运行（标准库版，拖拽功能自动禁用）
python RenameTool.py
```

如果需要拖拽功能：

```bat
pip install tkinterdnd2
python RenameTool.py
```

说明：

- `requirements.txt` 中运行时依赖为空，运行主体只使用 Python 标准库（tkinter、os、re、datetime、pathlib）。
- `tkinterdnd2` 是**可选**依赖，未安装时程序照常运行，只是拖拽入口禁用，状态栏会给出提示。

## 三、打包 exe 方法

先安装打包依赖：

```bat
pip install pyinstaller
```

根据是否安装 `tkinterdnd2` 选择其中一套命令：

```bat
:: 纯标准库版（不启用拖拽）
pyinstaller -F -w -n RenameTool RenameTool.py

:: 含拖拽版（已安装 tkinterdnd2）
pyinstaller -F -w -n RenameTool --collect-all tkinterdnd2 RenameTool.py
```

- `-F`：打包为单个 exe；`-w`：不显示控制台窗口；`-n`：指定输出名称。
- 打包完成后可执行文件位于 `dist\RenameTool.exe`。
- 含拖拽版必须带 `--collect-all tkinterdnd2`，否则运行时会因为缺少 tkdnd 动态库而无法启用拖拽（程序本身仍可运行）。
- 首次运行 exe 时若被 Windows SmartScreen 拦截，选择「更多信息 → 仍要运行」即可。

## 四、软件详细使用步骤

1. **添加文件**
   - 点击【选择文件夹...】选择目录；若需要连同子目录中的文件一起处理，先勾选「包含子文件夹」。
   - 或点击【添加文件...】直接多选若干文件。
   - 已安装 `tkinterdnd2` 时，也可以把文件 / 文件夹直接拖到窗口内。
   - 添加时表格初始为空，程序不会自动加载任何目录。
2. **（可选）后缀筛选**
   在「文件后缀筛选」输入框填写如 `jpg,png,txt`（逗号分隔、不区分大小写），不符合的文件在添加时会被忽略；表格中已有的文件会立即按新条件重新过滤（不会重新扫描磁盘）。清空输入框即关闭筛选，恢复显示所有已添加文件。
3. **配置改名规则**（四项可以同时使用，按固定顺序执行）
   - **正则替换**：勾选「启用正则替换」，填写正则表达式与替换内容（支持 `\1` 捕获组）；默认不区分大小写，需要区分大小写时勾选「大小写敏感」；需要连扩展名一起改时勾选「正则包含扩展名」。
   - **添加前缀 / 后缀**：在对应输入框填写即可，可只填一个。
   - **顺序编号**：勾选「启用顺序编号」，填写起始值（可负数）、步长（可负数）、补零位数（1-10 的整数），再选择「排序依据」（表格顺序 / 文件名称 / 修改时间 / 文件大小）。它只在文件名末尾追加 `_数字`。
   - **全局编号计数器（`{num}` 占位符）**：填写起始值、步长、补零位数（1-10）、排序依据，然后在前缀 / 后缀 / 正则「替换为」里写 `{num}`。这套计数器**不需要**勾选任何复选框；只想把文件整体改成纯数字名（如 `1.txt`、`20.txt`）时，保持「启用顺序编号」为未勾选，用正则 `^.*$`（或 `.*`）+ 替换为 `{num}` 即可，不会出现双重编号，也不会出现 `11`、`22` 这种重复插入。
   - **时间插入**：下拉选择「不插入时间 / 修改时间 / 创建时间」，并按需修改时间格式（默认 `YYYYMMDD_HHMMSS`，等价于 strftime 的 `%Y%m%d_%H%M%S`；也可直接填写任意 strftime 格式）。编号与时间都追加在主文件名末尾，编号在前、时间在后。
4. **查看预览**
   修改任意规则后会延迟 200ms 自动刷新预览。表格列出「原文件名 / 预览后的新文件名 / 文件路径」。
   - 存在重名、非法字符、保留名、路径超长等问题的行会**红色高亮**。
   - 只要出现任意一类问题，或者表格为空、或者所有新名字都与原名相同，【确认执行改名】按钮即为禁用状态。
   - 状态栏会给出对应说明（如「正则表达式无效」「检测到 N 行存在问题（红色高亮），确认改名已禁用」等）。
5. **执行改名**
   点击【确认执行改名】，在二次确认弹窗中确认「一共将要修改 N 个文件」后开始执行。执行过程中每处理 10 个文件刷新一次状态栏。
   - 全部成功：状态栏提示成功数量，表格「原文件名」列更新为新名字，「新文件名」列按当前规则重新运算，撤销按钮变为可用。
   - 中途失败：自动回滚已改名的文件，并弹窗告知失败原因；若回滚也有文件失败，会一并列出清单，本批次**不会**生成撤销记录。
   - 执行前若发现文件已被删除或路径变动，会直接放弃本次改名，请重新预览。
6. **撤销**
   点击【撤销上次改名】即可把最近一次成功批次改回原名；若部分文件已被删除或外部移动，会弹窗列出撤销失败清单。撤销完成（无论是否有失败项）后撤销记录立即清空、按钮置灰，表格刷新并重新预览。

## 五、风险注意事项

1. **请先用少量文件试运行**。批量改名是高风险操作，建议先复制一份文件做试验，确认规则与预览结果符合预期后再处理正式文件。
2. **撤销只有一次机会，且只在内存中**。程序关闭后撤销记录立即消失；新的成功改名批次会覆盖上一次的撤销记录；已执行过回滚的失败批次不产生撤销记录。
3. **时间精度带来的重名风险由用户自行承担**。程序只在预览阶段把冲突行高亮并禁用确认按钮，**不会自动去重**，也不会自动追加序号。若同一秒内多个文件产生相同时间戳，请自行加编号或调整时间格式（例如精确到毫秒 `%Y%m%d_%H%M%S_%f`）。
4. **创建时间降级**。非 Windows 系统或某些文件系统不支持创建时间时，程序会自动改用修改时间；仅在第一次切换到「创建时间」且无法获取时提示一次，后续预览不再重复弹窗。文件被复制、下载后，其「创建时间」通常会被重置，请确认这符合你的预期。
5. **正则包含扩展名有风险**。勾选后正则作用于完整文件名（含后缀），可能把扩展名改掉甚至改没（例如正则匹配整名并替换）。请务必在预览中确认。
6. **文件总路径长度限制**。新路径超过 255 字符的行会被判定为问题并高亮；在接近该长度的目录中改名时请特别留意。
7. **文件被占用会导致失败与回滚**。目标文件正在被其它程序（Office、播放器、杀毒软件、同步盘等）占用时改名会失败，程序会尝试回滚；**回滚不保证 100% 成功**，回滚失败的文件需要在弹窗清单中手动处理。
8. **执行前的检查有限**。程序只检查文件是否存在以及绝对路径是否与预览阶段一致，**不检查文件内容是否被修改**。
9. **不处理文件夹**。文件夹永远不会被重命名，也不会出现在表格中；表格内只有文件。
10. **多选不代表范围**。表格中多选行只用于目视对比，改名始终作用于表格内全部文件。
11. **同名占用**。若目标名字已被磁盘上其它文件占用，该行会在预览阶段被判为冲突并高亮（目标文件也在本批次中被改走的链式改名除外）。
12. **两个编号模块相互独立，注意不要重复叠加**。`{num}` 全局计数器与「启用顺序编号」末尾追加是两套独立的编号：若在前后缀里写了 `{num}` 又勾选了「启用顺序编号」，会先展开 `{num}`、再在末尾追加 `_数字`（例如 `5_003.txt`），请按需只启用其中一个。另外，`{num}` 计数器的步长若设为 0，所有文件会算出同一个编号并触发红色重名高亮。

## 六、更新记录

程序**标题栏会显示版本标记**，用它确认你运行的到底是哪一份文件。

- **v2.2**：修复 `.*` / `.*$` / `^.*` 这类“既能匹配整串、又能匹配空串”的正则模式——它们在整串匹配后还会在字符串末尾产生一次空匹配，`re.sub` 因此把替换串插入了两次（表现为 `{num}` → `11`、`22`、`33`）。现在 `.*` 与 `^.*$` 都能正确得到 `1`、`2`、`3`。
- **v2.1**：新增独立的全局编号计数器与 `{num}` 占位符——与「启用顺序编号」复选框完全无关，只替换占位符、绝不自动追加任何字符。
